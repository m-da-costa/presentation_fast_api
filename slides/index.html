03 · Conceito

O que é uma API? Pense num restaurante.

  • Você faz o pedido — pelo navegador, pelo Swagger ou por outro programa. Você nunca entra na cozinha.
  • O garçom (a API) leva o pedido à cozinha (o servidor) e volta com o prato — em JSON, o formato que programas entendem.
  • O cardápio é o contrato: diz o que dá pra pedir, com quais ingredientes, e o que volta. Sem cardápio, é chute.

No nosso caso o garçom se chama FastAPI — e o cardápio se escreve sozinho. 😏

04 · Por quê?

Por que FastAPI?

Em termos de garçom: “o FastAPI já chega com o cardápio escrito, conferido e traduzido.”

🐍

Pythônico e moderno

Os type hints que você já (vai) conhecer fazem o trabalho pesado. O código parece Python, não configuração.

✅

Validação automática

Pydantic confere o pedido antes de chegar na cozinha. Veio errado? 422, sem drama e com a explicação do erro.

📚

Documentação automática

Swagger UI (/docs) e ReDoc nascem do seu código. O cardápio se escreve sozinho.

⚡

Rápido e async

Starlette + Pydantic por baixo; async/await nativo quando a coisa fica séria.

🏢

Quem usa

Uber, Netflix, Microsoft, OpenAI… e, a partir de hoje, a nossa SentimentAPI. 🎬

🎯

Feito para aula

Um arquivo, meia dúzia de linhas, e já dá pra rodar, testar e quebrar ao vivo. Perfeito pra hoje.

09 · O contrato

Classes Pydantic = o contrato

main.py — os modelospython
class AvaliacaoEntrada(BaseModel):
    """O que o cliente ENVIA."""
    texto: str = Field(..., min_length=3, max_length=500,
                       description="O texto da avaliação do filme")
    nota: int = Field(..., ge=1, le=5,
                      description="Nota de 1 a 5 estrelas")
    autor: str | None = Field(default=None, max_length=60)


class AvaliacaoResposta(AvaliacaoEntrada):
    """O que a API DEVOLVE (herda e acrescenta)."""
    id: int
    criada_em: datetime
    sentimento: str    # positivo | negativo | neutro
    confianca: float   # de 0 a 1
  • A classe define a entrada: cada Field vira validação e descrição e exemplo.
  • E também a saída: response_model=AvaliacaoResposta no @app.post.
  • Herança: a resposta estende a entrada e acrescenta id, sentimento, confiança…
  • Tudo aparece modelado no Swagger, seção Schemas — o contrato desenhado.

10 · A mini-IA

A mini-IA: análise de sentimento

  • O léxico é só um dict: palavra → peso. “adorei” +3, “chato” −2…
  • classificar() tokeniza o texto, soma os pesos das palavras que conhece e dá o veredito.
  • A confiança cresce 0,1 por palavra reconhecida (teto 0,99).
🎬 “Chato, cansativo, perdi tempo” → −6 → negativo · confiança 0,99

🧸 Confissão honesta: é uma IA de brinquedo — legível linha a linha, sem mistério. Na próxima aula trocamos o léxico por scikit-learn… e a API nem muda de roupa.

main.py — o “cérebro”python
LEXICO: dict[str, int] = {
    "adorei": 3, "maravilhoso": 3, "excelente": 3,
    "emocionante": 2, "chato": -2, "cansativo": -2,
    "horrível": -3, "perdi": -1, "tempo": -1,
}

def classificar(texto: str) -> dict:
    palavras = texto.lower().replace("!", " ").split()
    encontradas = [(p, LEXICO[p]) for p in palavras if p in LEXICO]
    pontuacao = sum(peso for _, peso in encontradas)

    if pontuacao > 0:   sentimento = "positivo"   # 😊
    elif pontuacao < 0: sentimento = "negativo"   # 😩
    else:               sentimento = "neutro"     # 😐

    total = sum(abs(peso) for _, peso in encontradas)
    confianca = min(0.99, 0.5 + 0.1 * total)
    return {"sentimento": sentimento,
            "pontuacao": pontuacao,
            "confianca": round(confianca, 2)}
