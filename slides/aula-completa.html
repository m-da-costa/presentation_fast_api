01 · NumPy

O problema que o NumPy resolve

Listas do Python são flexíveis, mas não foram feitas para cálculo numérico em massa.

python puropython
valores = [10, 20, 30]

# dobrar cada valor
dobro = []
for v in valores:
    dobro.append(v * 2)
com numpypython
import numpy as np

valores = np.array([10, 20, 30])

# dobrar cada valor
dobro = valores * 2

Mesma tarefa. Menos código, mais legível e muito mais rápido — porque a repetição acontece dentro de código compilado, não no laço do Python.

01 · NumPy

Vetorização: a operação vale para o array inteiro

vetorizaçãopython
valores = np.array([10, 20, 30])

valores * 2
resultadoarray([20, 40, 60])

Sem laço. Sem índice. A operação se propaga elemento a elemento.

valores + 5 soma escalar a todos valores ** 2 eleva todos ao quadrado valores > 15 array de True / False a + b soma elemento a elemento

Máscara booleana — guarde este nome. valores > 15 devolve [False, True, True], e é exatamente assim que o Pandas filtra linhas no módulo 02.

02 · Pandas

Series e DataFrame

Duas estruturas, uma relação simples: um DataFrame é um conjunto de Series que compartilham o mesmo índice.

Series

uma coluna com índice

0 100 1 150 2 90 Name: vendas, dtype: int64
⊂
DataFrame

tabela com linhas e colunas

produto vendas 0 A 100 1 B 150 2 C 90

Cada coluna do DataFrame é uma Series. Puxar df["vendas"] devolve exatamente a Series da esquerda.

04 · APIs

O que é uma API? Pense num restaurante.

  • Cliente — quem faz o pedido (a sua aplicação). Você nunca entra na cozinha.
  • Garçom — leva o pedido e traz a resposta. É a API.
  • Cozinha — onde o trabalho acontece: sistema, banco, serviço.
  • O cardápio é o contrato — diz o que dá para pedir e o que volta. Sem cardápio, é chute.

API = Application Programming Interface. É isso que permite que aplicações escritas em linguagens diferentes troquem dados de forma padronizada.

04 · APIs

REST × SOAP

REST

estilo arquitetural

  • Normalmente sobre HTTP
  • Troca de dados frequentemente em JSON
  • Simples e amplamente adotado
  • Padrão em serviços web modernos
×
SOAP

protocolo formal

  • Protocolo com regras rígidas
  • Mensagens em XML (envelope)
  • Contrato formal descrito em WSDL
  • Comum em sistemas corporativos e legados

Você vai encontrar REST na maior parte dos serviços novos e SOAP em integrações bancárias, governamentais e de ERPs. Reconhecer os dois basta por enquanto.

05 · requests

Códigos de status HTTP

2xx · Sucesso

  • 200 OK
  • 201 Created

3xx · Redirecionamento

  • 301 Moved Permanently
  • 304 Not Modified

4xx · Erro do cliente

  • 400 Bad Request
  • 401 Unauthorized
  • 403 Forbidden
  • 404 Not Found
  • 422 Unprocessable
  • 429 Too Many Requests

5xx · Erro do servidor

  • 500 Internal Server Error
  • 503 Service Unavailable

401 é "não sei quem você é"; 403 é "sei quem você é, mas você não pode"; 429 é "calma, você está pedindo demais".

05 · requests

Tratamento de erros: três níveis

Toda requisição pode falhar — a rede cai, o token expira, o servidor sai do ar.

1 · verificar o statuspython
if response.status_code == 200:
    dados = response.json()
else:
    print("Erro:", response.status_code)
2 · deixar o requests avisarpython
response = requests.get(url)

response.raise_for_status()
dados = response.json()
3 · tratar a exceção — versão de produçãopython
try:
    response = requests.get(url, timeout=10)
    response.raise_for_status()
    dados = response.json()
except requests.exceptions.RequestException as erro:
    print("Erro ao acessar API:", erro)

timeout evita travar o script · raise_for_status() converte 4xx e 5xx em exceção · RequestException cobre rede, DNS e timeout

06 · FastAPI

Parâmetros no endpoint

parâmetro de caminhopython
@app.get("/produtos/{produto_id}")
def buscar_produto(produto_id: int):
    return {"produto_id": produto_id}
GET/produtos/10{"produto_id": 10}
GET/produtos/abc422

O type hint faz o trabalho. produto_id: int faz o FastAPI converter e validar o valor da URL. Uma chamada a /produtos/abc recebe um 422 com mensagem clara — sem você escrever uma linha de validação.

Endpoint POST e validação com Pydantic

main.pypython
from pydantic import BaseModel

class Produto(BaseModel):
    nome: str
    preco: float

@app.post("/produtos")

corpo da requisição{ "nome": "Mouse", "preco": 150.0 }
  • Campo faltando → 422
  • Tipo errado → 422
  • O modelo vira documentação

No POST os dados vêm no corpo da requisição, não na URL.
Mnemônico: Field no corpo, Query na URL.

O FastAPI testa as rotas de cima para baixo e para na primeira que casa. /produtos/{produto_id} casa com qualquer coisa depois de /produtos/. Regra prática: rotas com caminho fixo vêm antes das rotas com parâmetro.

06 · FastAPI

Boas práticas

1

Nomes claros para endpoints

/produtos, não /getProdutosNovo

2

Usar o método HTTP correto

GET consulta, POST cria, PUT atualiza

3

Validar os dados recebidos

Pydantic faz a maior parte do trabalho

4

Retornar o status adequado

201 ao criar, 404 quando não existe

5

Tratar erros

mensagem clara em vez de stack trace

6

Autenticar quando necessário

nem todo dado pode ser público

7

Nunca versionar segredos

tokens e senhas fora do código

8

Documentar os endpoints

descrições e exemplos nas funções

9

Versionar a API

/api/v1/… para não quebrar clientes

10

Separar regra de negócio

o endpoint chama; a lógica mora fora dele

07 · Exercício

Desafio

Uma API devolve a seguinte lista de produtos:

resposta da APIjson
[
  {"produto": "Notebook", "preco": 4500},
  {"produto": "Mouse", "preco": 150},
  {"produto": "Monitor", "preco": 1200}
]

Dica: se não houver uma API disponível, comece com a lista já em Python. O foco do exercício é o encadeamento das etapas, não a rede.

Sua tarefa

1Fazer a requisição com requests
2Transformar a resposta em DataFrame
3Calcular o preço médio
4Identificar o produto mais caro
5Criar um gráfico de barras
6Imaginar um endpoint FastAPI que disponibilize o preço médio

07 · Exercício · solução

Solução — obter, transformar, calcular

obter e transformarpython
import requests
import pandas as pd

response = requests.get(url, timeout=10)
response.raise_for_status()

df = pd.DataFrame(response.json())
calcularpython
media = df["preco"].mean()          # 1950.0

mais_caro = df.loc[df["preco"].idxmax()]
nome = mais_caro["produto"]          # "Notebook"
df produto preco 0 Notebook 4500 1 Mouse 150 2 Monitor 1200
✓R$ 1.950,00 — preço médio
✓Notebook — produto mais caro

idxmax() devolve o índice da linha com o maior valor; df.loc[índice] devolve a linha inteira — não só o preço.

import matplotlib.pyplot as plt
